## Goal

Expand the portable built-in sound library before starting the BeatLane6 rhythm game, while preserving the Markdown-first architecture and avoiding redistribution uncertainty from third-party sample libraries.

All newly bundled audio is generated deterministically by NoteScript source code and distributed under the project MIT license.

## Licensing boundary

The bundled production sounds are generated by `scripts/generate-core-sounds.js` and carry NoteScript project MIT metadata.

Third-party sampled instruments remain separate add-ons. A file being downloadable for free is not sufficient for bundling; its redistribution license must be checked before inclusion.

## Architecture

No new song language syntax was required.

Existing flow remains:

```text
Markdown song
    -> parser
    -> canonical timeline
    -> sound pack resolver
    -> renderer / audition / Studio
```

The portable builder already copies all `examples/sounds` packs into `sounds/`, so the expanded library is automatically present in portable builds.
