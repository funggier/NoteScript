# BeatLane6 Long-Form Song Pack

These five songs are original NoteScript compositions created specifically for BeatLane6. They use broad warm / jangly / dreamy / playful indie-pop characteristics without copying any existing song's melody, lyrics, or arrangement.

| Song | Tempo | Approx. length | Character | Normal chart |
| --- | ---: | ---: | --- | ---: |
| Sunlit Detour | 126 BPM | 1:09 | warm, bright, jangly | 556 events |
| Paper Satellites | 116 BPM | 1:15 | dreamy, floating, spacious | 462 events |
| Lemon Sky Arcade | 132 BPM | 1:06 | playful, bright, arcade-like | 577 events |
| Windowseat Polaroid | 104 BPM | 1:23 | mellow, nostalgic, hold-friendly | 402 events |
| Afterimage Parade | 142 BPM | 1:01 | fast, energetic finale | 588 events |

All songs:

- use four independent NoteScript tracks;
- contain 36 bars per track;
- use bundled SoundPiano/SoundPad sources only;
- generate deterministic Easy / Normal / Hard BeatLane6 charts;
- use all six lanes on every difficulty;
- include both Tap and Hold events on Normal;
- are copied into the portable `projects/` directory with human-readable filenames.

Suggested play order:

1. Windowseat Polaroid
2. Paper Satellites
3. Sunlit Detour
4. Lemon Sky Arcade
5. Afterimage Parade
