# BeatLane6 Long-Form Song

The current bundled long-form BeatLane6 example is an original NoteScript composition.

| Song | Tempo | Approx. length | Character | Normal chart |
| --- | ---: | ---: | --- | ---: |
| Sunlit Detour | 126 BPM | 1:09 | warm, bright, jangly | 556 events |

`Sunlit Detour`:

- uses four independent NoteScript tracks;
- contains 36 bars per track;
- uses bundled SoundPiano/SoundPad sources only;
- generates deterministic Easy / Normal / Hard BeatLane6 charts;
- uses all six lanes on every difficulty;
- includes both Tap and Hold events on Normal;
- is copied into the portable `projects/` directory as `Sunlit Detour.md`.
