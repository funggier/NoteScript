# Pluck Pack

Built-in deterministic plucked-string-style sound source for NoteScript.

```notescript-sound
name: Pluck
version: 1
author: NoteScript project
license: MIT
source: generated locally by scripts/generate-core-sounds.js
description: Deterministic Karplus-Strong pluck for rhythmic melodies.
type: pitched
fallback: nearest
sample C3 = C3.wav
sample C4 = C4.wav
sample E4 = E4.wav
sample G4 = G4.wav
sample C5 = C5.wav
```
