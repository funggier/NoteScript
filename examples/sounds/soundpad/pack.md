# SoundPad Pack

Built-in deterministic trigger sound source for NoteScript SoundPad.

```notescript-sound
name: SoundPad
version: 1
author: NoteScript project
license: MIT
source: generated locally by scripts/generate-core-sounds.js
description: Core named-trigger SoundPad with kick and shaker.
type: soundpad
trigger kick = kick.wav
trigger shaker = shaker.wav
```
