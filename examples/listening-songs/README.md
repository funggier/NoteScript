# Listening Songs

This pack contains ten original long-form NoteScript songs intended for relaxed listening and general playback testing.

| Song | Tempo | Approx. length | Lead sound |
| --- | ---: | ---: | --- |
| Morning Window | 84 BPM | 2:17 | Clean Electric Guitar |
| Rain on the Balcony | 76 BPM | 2:32 | Marimba |
| Slow Train Home | 88 BPM | 2:11 | Jazz Guitar |
| Cafe After Rain | 92 BPM | 2:05 | Acoustic Guitar |
| Cloud Pillow | 72 BPM | 2:40 | Vibraphone |
| River Lanterns | 80 BPM | 2:24 | Vibraphone |
| Sunday Pages | 86 BPM | 2:14 | Marimba |
| Quiet Neon | 90 BPM | 2:08 | Synth Bass |
| Garden at Four | 78 BPM | 2:28 | Nylon Guitar |
| Moonlit Tea | 74 BPM | 2:36 | Jazz Guitar |

Each song:

- contains 48 bars per track;
- uses four independent tracks;
- uses bundled NoteScript SoundPiano and SoundPad sources only;
- targets roughly two to three minutes of playback;
- is bundled into the portable `projects/` directory.
